# StudyMate AI

A mobile-first simulated study assistant prototype.

## Features
- Study-help chat with built-in beginner-topic responses
- Study-plan generator (30, 45, 60, 90 minutes)
- Python quiz with answer feedback and score tracking
- Responsive phone-friendly design
- Progress saved locally in the browser

## Limitation
This starter uses local demo logic. It is **not connected to a live AI model, Alexa+, an Agent Skill, or an MCP server**. Do not claim it has a live AI integration.

## Run
Open `index.html` in a modern browser. No build step or API key is required.

## GitHub Pages
1. Create a new public repository named `studymate-ai`.
2. Upload `index.html`, `README.md`, `LICENSE`, and `.nojekyll` to the repository root.
3. Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
4. Wait for the site URL to appear in Pages settings, then open that exact URL.
5. Test chat prompts, plan generation, quiz answers, and mobile layout.
